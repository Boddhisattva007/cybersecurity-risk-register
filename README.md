# Cybersecurity Risk Register

A React application for recording and managing cybersecurity risks.

## Main Features

- Add new cybersecurity risks
- Edit existing risks
- Delete risks
- Calculate risk scores based on likelihood and impact
- Assign Low, Moderate, High, or Critical severity levels
- Filter risks by severity and status
- View a summary of recorded risks

## Software I Used

- React
- JavaScript
- JSX
- HTML
- CSS
- React Router
- Vite

## Risk Calculation

Risk Score = Likelihood × Impact

- 1–4: Low
- 5–9: Moderate
- 10–16: High
- 17–25: Critical
